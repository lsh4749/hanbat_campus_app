# 역할 및 목표
Flutter(Dart)를 사용하여 익명/모임 실시간 채팅 기능의 UI와 기본 인터랙션을 구현해줘.
현재 팀 프로젝트의 `lib/chat/` 디렉토리 내부를 담당하고 있으며, 외부 패키지 의존성을 최소화하고(기본 `material.dart` 위주) 즉시 실행 및 테스트가 가능하도록 Mock 데이터를 포함해 구현해야 해.

---

# 파일 구조 제안 (`lib/chat/`)
유지보수가 쉽도록 아래와 같이 모듈화해서 작성해줘.
- `lib/chat/models/chat_models.dart`: 채팅방, 메시지(텍스트/사진/동영상), 답장 참조, 읽음 상태 데이터 모델
- `lib/chat/utils/time_formatter.dart`: 상대 시간 및 채팅방 날짜 구분선 포맷터
- `lib/chat/screens/chat_repo_screen.dart`: 채팅방 목록 화면 (진입점)
- `lib/chat/screens/chat_screen.dart`: 개별 채팅방 화면 (기존 `ChatScreen` 대체)
- `lib/chat/widgets/`: 말풍선, 답장 프리뷰, 미디어 위젯 등 재사용 컴포넌트

# 화면 1: 채팅 목록 (`ChatRepoScreen`)
1. **헤더 및 필터**
   - 상단 타이틀: `익명 메시지`
   - 필터 칩(Pill 버튼): `[전체]`, `[읽지 않음]` (선택된 탭 강조 표시, `[읽지 않음]` 선택 시 안 읽은 메시지가 있는 방만 필터링)
2. **내 프로필 영역 (리스트 최상단 고정)**
   - 구성: 원형 프로필 아이콘 + `{my_id}` + 우측 `나 >` 텍스트
   - 동작: **터치 시 아무런 기능도 실행하지 않음** (단순 표시용)
3. **채팅방 리스트 아이템**
   - 구성: 좌측 원형 프로필 이미지 / 중앙 `{모임 이름}`(굵게, 1줄 말줄임) 및 최근 메시지 `내용`(회색, 1줄 말줄임) / 우측 `상대 시간` + `>` 아이콘
   - 안 읽은 메시지가 있는 방은 시각적으로 구분(예: 작은 파란 점 또는 굵은 텍스트)
   - **상단 고정(Pin) 정렬 규칙**: 즐겨찾기(★)된 채팅방은 리스트 최상단(`{my_id}` 바로 아래)에 고정되며, **여러 개일 경우 가장 최근에 별을 누른 순서대로** 정렬됨. 고정되지 않은 방은 최신 메시지 순으로 정렬.
4. **상대 시간 포맷팅 규칙 (`time_formatter.dart`)**
   - 오늘(하루 미만): `오후 3:46` (오전/오후 + 시:분)
   - 어제: `어제`
   - 2일 ~ 6일 전: `2일 전`, `3일 전` ... `6일 전`
   - 1주 ~ 3주 전: `1주일 전`, `2주일 전`, `3주일 전`
   - 4주 이상(1달 이상): `1달 전` ... `26달 전` (**년 단위로 변환하지 않고 계속 'N달 전'으로 표시**)

# 화면 2: 채팅방 (`ChatScreen`)
1. **상단 AppBar**
   - 좌측: 뒤로가기 버튼(`<`), 상대방/모임 프로필 아이콘, `{id 또는 모임이름}`
   - 우측: 별 아이콘(`☆` / `★`). 누르면 해당 채팅방의 **상단 고정 상태 토글** (고정 시 현재 타임스탬프를 기록해 최신 고정 순 정렬에 반영).
2. **메시지 말풍선 디자인 및 그룹핑**
   - 모양: 둥근 사각형(Stadium/RoundedRectangle, `BorderRadius.circular(18)` 정도). 최대 너비는 화면 너비의 70%로 제한.
   - 색상: 내 메시지 = 파란색 배경(흰 글씨, 우측 정렬), 상대 메시지 = 회색 배경(검정 글씨, 좌측 정렬).
   - **연속 메시지 처리**: 같은 발신자가 연속으로 여러 개를 보낸 경우, **프로필 사진은 1개만 표시** (첫 번째 또는 마지막 메시지 기준 통일).
   - **모임(그룹) 채팅 표시**: 모임 채팅방인 경우 상대방 프로필 사진 옆(또는 말풍선 상단)에 발신자 `id`를 표시. 연속 메시지일 때는 프로필 사진과 마찬가지로 **1번만 표시**.
   - **날짜/시간 구분선**: 메시지 간 시간 간격이 30분 이상이거나 날짜가 바뀔 때 중앙에 `12월 5일 오후 9:16` 형태로 표시.
3. **지원 메시지 타입 (텍스트, 사진, 동영상)**
   - `text`: 일반 텍스트 말풍선
   - `image`: 둥근 사각형 이미지 카드 (Mock에서는 `Image.network` 또는 플레이스홀더 컨테이너 사용)
   - `video`: 둥근 사각형 썸네일 카드 + 중앙 재생(▶) 아이콘 오버레이
4. **답장(Reply) 기능**
   - 메시지 길게 누르기(LongPress) 또는 스와이프로 답장 대상 지정 가능.
   - 답장 메시지 렌더링: 상단에 `답장을 보냈어요.` 회색 텍스트 + 좌측 세로선(`|`) + 원본 메시지 미리보기(텍스트는 요약, 사진/동영상은 **작은 썸네일 표시**).
   - **원본 이동 인터랙션**: 답장 미리보기 영역을 탭하면 해당 원본 메시지의 위치로 스크롤 이동(`GlobalKey` + `Scrollable.ensureVisible` 등 활용)하고, 1초간 살짝 하이라이트 효과 적용.
5. **읽음/읽지 않음 표시**
   - 메시지 하단(또는 가장 최근에 읽힌 메시지 아래)에 읽음 상태 표시 (예: `id_1님이 읽음, id_2님이 읽음` 또는 `읽지 않음`).
   - 읽은 사람이 많아 **내용이 길어질 경우 1줄로 자르고 말줄임(`TextOverflow.ellipsis`)** 처리.
6. **하단 입력창**
   - 둥근 알약 모양 입력 필드 (`메시지 보내기..` 힌트 텍스트)
   - 우측에 사진/동영상 첨부 버튼(갤러리 아이콘)과 전송 버튼(텍스트 입력 시 활성화) 배치.
   - 실제 메시지 전송 시 리스트 최하단에 추가되고 스크롤이 맨 아래로 내려가도록 구현.
