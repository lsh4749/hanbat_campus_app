# 채팅방 클래스
- ID
- 제목
- 아바타 (사진)

- 고정 시각

# 메시지 클래스
- ID, 발신자 ID
- 발신자 닉네임
- 발신자 아바타 (사진)
- 메시지 유형(텍스트/사진/동영상)
- 메시지 내용
- 전송 시각 읽음 처리된 유저 ID 목록
- 답장 참조(원본 메시지 ID, 원본 발신자 닉네임, 원본 메시지 내용 일부)
